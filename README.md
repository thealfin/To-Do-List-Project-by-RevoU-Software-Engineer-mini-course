## Features

### MVP
| Feature | Description |
|---|---|
| ⏰ Live Clock & Date | Shows current time and full date in the topbar |
| 👋 Greeting | Adapts greeting to time of day (morning / afternoon / evening / night) |
| 🍅 Focus Timer | 25-min Pomodoro with SVG ring progress, Start / Stop / Reset |
| ✅ To-Do List | Add, edit, mark done, delete — saved in Local Storage |
| 🔗 Quick Links | Add, delete, favicon auto-loaded — saved in Local Storage |

### Bonus Challenges (All 5 ✅)
1. **Light / Dark mode** — toggle in the topbar
2. **Custom name in greeting** — click "Edit name" under the greeting
3. **Change Pomodoro time** — edit the minute field in the timer card header
4. **Prevent duplicate tasks** — case-insensitive check before adding
5. **Sort tasks** — dropdown: Default / A→Z / Z→A / Done last

## Getting Started

### Run locally
Just open `index.html` in your browser — no build step needed.

### Deploy to GitHub Pages
1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set **Source** to `main` branch, root (`/`)
4. Your site will be live at `https://<username>.github.io/<repo-name>`
